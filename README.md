## How to run project

1. Clone my rep on GitHub
```bash
git clone https://github.com/MyhailoTim/Web.git
```
2. Create virtual env
3. Install dependencies
```bash
pip install -r requirements.txt
```
4. Apply migrations
```bash
python manage.py migrate
```
5. Run the server
```bash
python manage.py runserver
